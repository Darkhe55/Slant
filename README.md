# 划斜线 Gokigen Naname

一个基于 Web 的画斜线（Gokigen Naname / ごきげんななめ）谜题游戏，原生 SVG 渲染，内置逻辑解题器。

## 在线体验

克隆后运行：

```bash
npm install
npm run dev
```

浏览器打开终端显示的地址（默认 `http://localhost:5174`）。

## 游戏规则

在格子中画对角线：

- 每格必须填入一条对角线：`\` 或 `/`
- 顶点上的数字，等于经过该顶点的对角线条数（0–4）
- 所有对角线不得闭合成环

## 功能

- **题库**：内置 8 道题，从 4×4 入门到 9×9 挑战，均校验唯一解
- **自定义题**：在侧边栏摆放顶点数字，载入后即可游玩；支持键盘录入（方向键移动，0–4 填数，. / 退格清空，Enter / Tab 下一格，Esc 关闭）
- **逻辑解题**：点击"逻辑解题"从当前进度自动推理，动画展示每一步并说明理由；连拍逐步加速（每推一步升一档，与填充的是 \ 还是 / 无关，不重置）
- **推理规则**：顶点饱和度、环路规避、相邻数字对的非公共格额度推导（已连数 + 公共格数 ≥ 两数字之和 → 空格全相背；已相背数 = 非公共格 + 公共格 − 两数字之和 → 空格全相连；相邻 1-1 / 3-3 为其特例，贴墙按实际格数自动弱化）
- **音效特效**：落子播放弦振拨弦 + 沿线抖动，排除播放水滴 + 涟漪，连拍逐级抬音高
- **实时校验**：数字冲突标红、已满足变灰、成环部分红线高亮
- **进度保存**：自动保存每道题的进度，刷新不丢失
- **撤销/重做**：按手势分组，一次拖拽涂写只需一步撤销
- **提示一格 / 显示解**、悬停预览、滚轮缩放、中键平移

## 技术栈

- Vite + TypeScript
- 原生 SVG（无框架）
- Web Audio 合成音效（无外部资源）
- localStorage 存储进度

## 项目结构

```
src/
  main.ts         主逻辑：UI、交互、解题回放、音效调度
  render.ts       SVG 棋盘渲染、命中检测、缩放度量
  logic.ts        逻辑解题规则引擎（规则 1-4）
  solver.ts       回溯求解器（唯一解校验）
  audio.ts        Web Audio 音效合成（拨弦 / 水滴）
  fx.ts           落子特效（弦振 / 形变 / 涟漪）
  puzzles.ts      题库加载
  puzzles-data.ts 静态题库数据（自动生成）
  state.ts        棋盘状态与索引换算
  validate.ts     解的合法性校验（数字 + 环路）
  types.ts        共享类型
```

# 斜线 · Gokigen Naname

网页版「画斜线」逻辑谜题（ごきげんななめ / Gokigen Naname）。Vite + TypeScript + 原生 SVG，无框架。

## 玩法

- 每格画一条对角线：`\` 或 `/`
- 顶点上的数字 = 经过该顶点的对角线条数（0–4）
- **所有斜线不得闭合成环**

## 快速开始

```bash
npm install
npm run dev        # http://127.0.0.1:5174
```

## 操作

| 操作 | 说明 |
|------|------|
| 左键点格子 | 循环：空 → `\` → `/` → 空 |
| 右键点格子 | 反向循环 |
| 按住左键拖拽 | 以第一格的方向连续涂 |
| 滚轮 | 以光标为锚点缩放 |
| 中键拖拽 / 点在盘面外拖拽 | 平移 |
| `Z` / `Shift+Z` | 撤销 / 重做 |
| `C` / `H` / `S` / `Esc` | 检查 / 提示一格 / 显示解 / 清空 |
| `R` / `L` | 随机抽题 / 逻辑解题 |
| `+` `-` `0` | 放大 / 缩小 / 复位视图 |

## 功能

- 8 道内置题（4×4 到 9×9，入门→挑战），全部经过**唯一解**校验
- 实时校验：数字冲突标红、已满足变灰、环路部分红线高亮
- 提示一格 / 显示参考解（可撤销）、撤销重做按手势分组
- 自定义题板：自己摆顶点数字，「唯一解校验」一键确认
- 进度自动存 localStorage，刷新不丢
- 悬停预览：格子高亮 + 虚线预览即将落下的对角线

## 逻辑解谜器

`src/logic.ts` 是人类规则推理器，目前实现了两条规则：

- **规则 1 · 顶点饱和度**：顶点的**连接数已足够**（`conn === N`）→ 剩余格子全部填「背朝」方向；
  顶点的**非连接数已和数字互补**（`conn + unk === N`）→ 剩余格子全部填「连朝」方向
- **规则 2 · 环路规避**：某格填某方向会把两个**已经连通**的顶点接上（立刻闭合成环）→ 只能填另一个方向

点「逻辑解题」（或按 `L`）会从当前进度开始推理，并逐条动画演示：高亮正在推的格子、
状态栏说明理由，再落子；再按一次可中途停止，推得的格子可正常撤销。

当前成绩（`npm run logic-test`）：4×4 / 5×5 / 6×6 / 7×7 全部推完；8×8 推 52 步（剩 12）、
9×9 推 35 步（剩 46）。下一条是规则 3（试填 + 传播），实测能把整个题库推完。

详见 [DESIGN.md](./DESIGN.md)。
